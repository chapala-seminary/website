## Problems in the English source

1. **SA keywords_en**: every item is 4 concepts written twice (EN stem + ES stem, e.g. "receiv"/"recib"). That is 8 groups, but a student really needs only 2 concepts to reach 3 hits in a bilingual answer. In French I made 8 distinct concept groups (the group count is unchanged). This makes French grading somewhat stricter than English and Spanish. Robert should check whether the English/Spanish keywords were meant this way.
2. **SA6 model** says the Critical Text "omits" the Comma. The lesson (b020) says the modern versions *footnote* it ("Print the Comma or footnote it"). This is a small inconsistency, and I translated it faithfully ("l'omet").
3. **b020 / MC16**: the story that Erasmus added the Comma after promising to do so if a single Greek manuscript were produced is disputed by Erasmus scholars (H. J. de Jonge). The lesson words it carefully ("under pressure"), but you may want to soften it.
4. **b018**: "recovered from a wastebasket" repeats Tischendorf's own account of Sinaiticus, which historians question. It is acceptable here because it is presented as the TR side's rhetoric.
5. **Fill 3**: the English alternates include "NA28". I kept NA28 and added the spacing variant "NA 28". These alternates will go stale with NA29.

- Critical / Eclectic Text → Texte critique / éclectique
- Majority Text → Texte majoritaire
- Byzantine text → texte byzantin
- reading (textual variant) → variante / formulation
- scribe → copiste
- codex/codices → codex (invariable)
- longer ending of Mark → finale longue de Marc
- Comma Johanneum → Comma johannique
- cardinal doctrine → doctrine cardinale
- preservation → préservation
- deity of Christ → divinité de Christ
- in-house disagreement → désaccord interne / affaire de famille
- unchurch → exclure de l'Église
- Erasmus / Stephanus / Beza / Elzevirs → Érasme / Estienne (Stephanus) / Bèze / Elzevier
