## 3. Terms for the reviewer to confirm

- **probing question** → question exploratoire — Central WiseSpeak step name; alternatives « question d'investigation » or « question d'approfondissement ». Must match the term used in units 1–10.
- **keyword / subject / objective** → mot-clé / sujet / objectif — Standard French homiletic terms; 'sujet' risks confusion with grammatical subject (as in ws0-078) but is the usual term for a sermon's subject.
- **outline** → plan — French homiletics normally says « plan » for a sermon outline.
- **pulpit note** → note de chaire — No fixed French term; « fiche de chaire » is another option.
- **extemporaneous preaching** → prédication improvisée — « extemporanée » is rare in French; « improvisée » may sound like 'unprepared', which the sentence itself rules out. Alternative: « prédication sans notes ».
- **Short-essay scenarios** → Mises en situation à courte dissertation — Wording should match the label used in the unit packets.
- **Certificate / Associate / Th.M. / M.Div. (tracks)** → Certificat / Associé / Th.M. / M.Div. — Matches other CTS French units ('Parcours Certificat / Associé').
- **Doctrinal Preaching / Evangelistic Preaching (course names)** → Prédication doctrinale / Prédication d'évangélisation — Course titles not yet fixed in French; « Prédication évangélistique » is an alternative.
- **Doulos (Greek for bondservant)** → Doulos (mot grec signifiant « esclave », serviteur) — LSG usually renders doulos 'serviteur'; Spanish edition uses 'esclavo'. Both given.
- **This certifies that** → Nous certifions que — Alternative: « Le présent certificat atteste que ».
